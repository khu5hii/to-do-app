# ✅ Plannit

A simple and clean **To-Do application built with React** that helps users manage daily tasks efficiently. The app allows users to add, complete, and delete tasks with a smooth and responsive user experience.

---

## 🌐 Live Website

👉 **Live Demo:**  https://plannitapp.vercel.app/

---

## ✨ Features

### 📝 Task Management
- Add new tasks instantly  
- Mark tasks as completed  
- Delete tasks when no longer needed  

### ⚡ Real-Time Updates
- UI updates instantly without page reloads  
- Powered by React state management  

### 🎯 Clean & Minimal UI
- Simple layout focused on productivity  
- Easy-to-use interface for all users  

### 📱 Responsive Design
- Works smoothly on desktop, tablet, and mobile screens  

---

## 🧠 How It Works

- Tasks are stored in React state  
- Adding a task updates the task list dynamically  
- Completing a task toggles its status  
- Deleting a task removes it from the state and UI
